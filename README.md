# proyecto-web-ia

Explorador interactivo de personajes de **Rick and Morty** desarrollado con **HTML, CSS y JavaScript** puro.

El objetivo del proyecto es consumir una API pública real y construir una interfaz donde el usuario
pueda buscar, filtrar, ordenar y guardar personajes favoritos.

> Proyecto académico — Desarrollo web con inteligencia artificial.
